# Desenvolvedor Back-End - Turma 176A.DBKE.2N26
Repositório com as atividades desenvolvidas no curso do **SENAI de Americana** para qualificação em **Desenvolvimento Back-End**.
## 🎯 Objetivo do curso 🎯
O curso de Qualificação Profissional de Desenvolvedor Back-End tem por 
objetivo o desenvolvimento de competências que permitem projetar, desenvolver e 
manter sistemas e aplicativos na parte do servidor e seguindo boas práticas, 
procedimento e normas.

## 📌 Sobre este repositório 📌

Este repositório reúne exercícios e projetos práticos organizados por módulos de estudo, com foco em:

- Lógica de programação e algoritmos
- Programação orientada a objetos
- Banco de dados
- Desenvolvimento de APIs

## 🧰 Tecnologias utilizadas 🧰

- **C#** (principal)
- **SQL / T-SQL**

### 🗄️ Banco de dados

Módulo com foco no desenvolvimento de aplicações que utilizam banco de dados com a técnica ORM realizando as operações CRUD :
- CREATE -> CRIAR
- READ -> LER
- UPDATE -> Atualizar
- DELETE -> Deletar
  Com elaboração de algumas consultas (querys) SQL mas os projetos em sua maioria foram desenvolvidos com ORM -> Objeto Relacional Mapeado.
